Remember your test setup

Profiles remember phones, Android packages and activities. Pairing tokens stay in memory. Connecting preserves app data; launch is a separate action.

Import Appium-style capabilities

Imports udid, appPackage, appActivity and platformVersion. Driver, reset, animation and autolaunch options are ignored. This tool controls Compose through QaLens.

Saved components

SHA-256 identifies attributes plus tree position, package and viewport. Changed values or positions produce a new file. Timestamps and live IDs do not.

Process a saved component

Configure processors in a local pipeline JSON file when starting the server. Each step receives the saved component path and an output directory. Runs are explicit; commands are never retried.

Select and save a component in the inspector or library first.

Run history is saved in each output directory; this view lists runs started during this server session.
