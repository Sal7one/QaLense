# Repository entry point

Read [HANDOVER.md](HANDOVER.md) before working in this repository. It contains the current project
context, user priorities, tested toolchain, verification commands and engineering contracts.
[Next work](next.md) is the only current backlog. [CONTRIBUTING.md](CONTRIBUTING.md) has portable
build and device-test instructions. Historical CHANGELOG entries are not a current baseline.

Preserve host-app behavior, debug/no-op release isolation, explicit capture privacy and honest
recording coverage. Do not commit secrets, local configuration, generated builds or real recordings.
For host-app integration, use [integration.md](integration.md) and [OSS integrations](docs/OSS_INTEGRATIONS.md).
