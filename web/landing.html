Backend — the mock webhookpython · stdlib only

A zero-dependency local server that stands in for your AI-analysis backend: receives every hook, parses each .sal, and returns a deterministic mock AI verdict. Swap one function for your real LLM call.

📡

Both hooks, one endpoint

POST /webhook takes the mobile multipart upload and the web player upload; POST /api/ingest takes JSON summaries.

🧠

Mock AI verdict

Severity, likely owner, confidence, and evidence — derived from the recording's own analysis.json. The verdict body is what the Control Room shows under each recording.

🧩

Chunked & resumable

Large recordings stream in 1 MB chunks with CRC32 and resume — flaky QA-lab Wi-Fi is fine.

🖥

Live dashboard

Uploads arrive live with score, owner, and verdict; click a card for the full digest, download the .sal, delete it.
